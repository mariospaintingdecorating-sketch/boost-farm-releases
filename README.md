# Boost Farm for Android

An independent Android application for managing Acki Nacki wallets and collecting Boost rewards.

- Wallet overview and reward status.
- Automatic and manual Boost collection.
- Premium access for additional wallets.
- English, Polish, Russian and Turkish.

## Download

[Download the latest APK](https://github.com/mariospaintingdecorating-sketch/boost-farm-releases/releases/latest)

Open **Assets** and select the `.apk` file. To update, install the new version over the existing app without uninstalling it. Background operation depends on Android permissions, device settings and network availability.
